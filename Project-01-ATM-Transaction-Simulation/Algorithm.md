# Algorithm – ATM Transaction Simulation

1. Start the program.
2. Initialize the account balance to ₹10,000.
3. Create an empty transaction list.
4. Display the ATM menu.
5. Accept the user's choice.
6. If the choice is 1, display the account balance.
7. If the choice is 2, accept the deposit amount and check whether it is at least ₹100.
8. If valid, update the balance and store the transaction.
9. If the choice is 3, accept the withdrawal amount.
10. Validate the withdrawal amount and maximum withdrawal limit of ₹5,000.
11. Check whether the remaining balance is at least ₹500.
12. If valid, update the balance and store the transaction.
13. If the choice is 4, display transaction history.
14. If the choice is 5, display the final balance and transaction count.
15. Exit the program.
16. For an invalid choice, display an error message.
17. Repeat until the user selects Exit.
