# ATM Transaction Simulation

## Project Overview
A simple ATM Transaction Simulation developed using Python. It allows users to perform basic banking operations.

## Features
- Check Account Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Final Balance Summary
- Transaction Validation

## Technologies Used
- Python
- NIAT Online Python Compiler

## Initial Balance
₹10,000

## Python Concepts Used
- Variables
- Data Types
- Operators
- Conditional Statements
- Loops
- Lists

## How to Run
1. Open the Python compiler.
2. Copy the code from `atm.py`.
3. Run the program.
4. Select the required ATM operation.
